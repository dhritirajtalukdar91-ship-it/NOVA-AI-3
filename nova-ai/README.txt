NOVA AI - Chat app powered by Claude

SETUP
1. Get an API key at https://console.anthropic.com
2. Open index.html in any modern browser (Chrome, Edge, Firefox, Safari)
3. Paste your API key in the Settings popup and click Save
4. Start chatting!

NOTES
- Needs an internet connection (Claude API + fonts/markdown library from CDN).
- Your key is stored only in your browser (localStorage), sent only to Anthropic.
- API usage is billed to your Anthropic account.
- Models: Sonnet 5.5 (balanced), Opus 5.5 (most powerful), Haiku 5.5 (fast).
